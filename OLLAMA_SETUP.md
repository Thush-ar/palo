# Ollama setup for PaLO

PaLO uses **Ollama** to run a local LLM for **Talk to AI** and **LLM-powered MCQ generation**. Follow these steps.

## 1. Start Ollama

- **Windows:** Open the Ollama app from the Start menu, or run `ollama` in a terminal. The server runs in the background.
- **Mac/Linux:** In a terminal, run:
  ```bash
  ollama serve
  ```
  Leave this terminal open while using PaLO.

## 2. Pull a model

In a **new** terminal (or Command Prompt), run one of:

```bash
ollama pull llama3.2
```

or:

```bash
ollama pull llama2
```

PaLO will automatically use the first available model it finds (llama3.2, llama3, llama2, mistral, or phi).

## 3. Check that Ollama is running

- Open: http://localhost:11434
- Or run: `ollama list` — you should see your pulled model(s).

## 4. Use PaLO

1. Run PaLO (e.g. run `OfflineTutorApp` or your main class).
2. **Talk to AI:** Choose **Talk to AI** on the mode screen → chat with the model.
3. **Scan + quiz:** Choose **Scan Pages** → scan a page → MCQs are generated by the LLM.

## Troubleshooting

| Issue | What to do |
|--------|------------|
| "Ollama is not running" | Start Ollama (see step 1). On Windows, open the Ollama app. |
| No model found | Run `ollama pull llama3.2` or `ollama pull llama2`. |
| Slow first reply | First request loads the model into memory; later ones are faster. |
| Port in use | Ollama uses port **11434**. Close anything else using it, or change the URL in `LlamaConnection.java` if you run Ollama on another port. |

## Changing the model

Edit `LlamaConnection.java`: update the `PREFERRED_MODELS` array so your preferred model name is first. The app picks the first model in that list that exists on your machine.
